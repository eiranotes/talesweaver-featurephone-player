설정

테일즈위버 피처폰 복원판

이스핀편·막시민편 LGT WIPI/C 파일을 브라우저에서 직접 실행합니다. 업로드한 게임 ZIP과 세이브 데이터는 이 브라우저의 로컬 저장소에 남습니다.

  1. 게임 파일 추가LGT판 테일즈위버 ZIP 파일을 선택합니다.
  2. 실행추가된 테일즈위버 아이콘을 누릅니다.
  3. 조작PC는 방향키/Space, 모바일은 화면 키패드를 사용합니다.

게임 파일 추가

테일즈위버 이스핀편 또는 막시민편 LGT ZIP 파일을 선택하세요. 파일은 서버로 전송되지 않습니다.

세이브

게임 내 저장은 자동으로 이 브라우저에 유지됩니다.
아래 기능은 세이브 데이터를 파일로 백업하거나 다른 기기에서 복원할 때 사용합니다.

테스트 플레이 잠금

테스트 사용자용 페이지입니다. 비밀번호를 입력하면 게임 데이터를 복호화해 이 브라우저에서 실행합니다.
